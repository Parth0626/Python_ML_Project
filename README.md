# Python_ML_Project

**📘 Overview
This project involves building a Machine Learning model to **predict the expected salary (CTC)** of job applicants based on various features such as experience, qualification, and skillset.

**🎯 Objective
This Model helps to predict the salary for new applicants using historical data, minimizing bias and improving efficiency in the recruitment process.

**📁 Files Included
  - Data preprocessing
  - Exploratory Data Analysis (EDA)
  - Feature engineering
  - Model building (Random Forest)
  - Final predictions and observations
